# Task Flow Dashboard

本案例展示如何将团队的任务流（例如看板、里程碑与交付状态）组织成可扩展的 UI 结构。

## 交互目标

- 过滤与布局动画的协同
- 信息密度与可读性的平衡

## 动画与布局

当筛选条件变化时，卡片进出与位置重排需要保持“连续的视觉流”。这也是本项目里使用 `AnimatePresence` 与 `layout` 的原因。

## 片段：筛选动画思路

```tsx
<AnimatePresence mode="popLayout" initial={false}>
  {items.map((item) => (
    <motion.div key={item.id} layout>
      ...
    </motion.div>
  ))}
</AnimatePresence>
```

# Task Flow Dashboard

This case study shows how to organize team workflows (kanban, milestones, and delivery status)
into a scalable UI structure.

## Interaction goals

- Smooth coordination between filtering and layout animation
- Balance between information density and readability

## Animation and layout

When filters change, card entry/exit and reordering should keep a continuous visual flow. That is
why this project uses `AnimatePresence` and `layout`.

## Snippet: filtering animation pattern

```tsx
<AnimatePresence mode="popLayout" initial={false}>
  {items.map((item) => (
    <motion.div key={item.id} layout>
      ...
    </motion.div>
  ))}
</AnimatePresence>
```

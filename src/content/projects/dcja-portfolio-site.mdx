# DCJA Team Portfolio

This is a sample team portfolio and narrative case-study page focused on:

- Modern motion design
- Clear information hierarchy
- Reusable components and types

## Highlight: Type-safe UI data

Define a single `Project` interface in the data layer and reuse it across components like
`ProjectGrid` and `TechBadge`, so TypeScript can catch data-shape changes early.

## Example: Component structure

```tsx
export interface ProjectGridProps {
  projects: Project[]
}

export default function ProjectGrid({ projects }: ProjectGridProps) {
  // render...
}
```

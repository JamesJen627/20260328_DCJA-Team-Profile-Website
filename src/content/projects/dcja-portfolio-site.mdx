# DCJA Team Portfolio

这是一个团队作品墙与叙事型案例页面的示例，重点围绕：

- 现代动效体验
- 清晰的信息层级
- 可复用的组件与类型

## 亮点：用类型约束 UI 数据

在数据层定义统一的 `Project` 接口，再把它贯穿到 `ProjectGrid`、`TechBadge` 等组件中，让“数据结构变化”更容易被 TypeScript 捕获。

## 示例：组件如何组织

```tsx
export interface ProjectGridProps {
  projects: Project[]
}

export default function ProjectGrid({ projects }: ProjectGridProps) {
  // render...
}
```

## 结语

本示例用于验证 MDX（远程/按需渲染）在详情页中的集成方式。
